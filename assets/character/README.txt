마스코트 이미지 폴더
====================
파일명 규칙(01_default ~ 10_empty)에 맞춰 자동 연결됩니다.

포털에서 쓰는 표정:
01_default.png  - 기본 (다른 표정이 없을 때 대체)
02_smile.png    - 인사 (홈·페이지 머리)
03_cheer.png    - 축하 (퀴즈 만점)
04_surprise.png - 경고 (환수 위험, 소득 급감)
06_sad.png      - 아쉬움 (오답·검색 결과 없음)
07_wink.png     - 팁 (알아두세요 말풍선)
08_love.png     - 안심 (안전 판정)
09_thinking.png - 생각 (검색·계산 화면)

05_sleepy, 10_empty, mascot_expressions_sheet는 현재 미사용(예비).
이미지를 교체하면 포털 새로고침(F5) 시 바로 반영됩니다.
